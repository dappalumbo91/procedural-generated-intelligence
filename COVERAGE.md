# Coverage

How much of each physics domain is on PGI's board, and what is missing. Every board record is assigned to one domain by `pgi/corpus/coverage.py`, and `python -m pgi.corpus.coverage` prints the table. The tests check that every record has a domain and that both generated blocks below match the board, so this file cannot drift.

The counts are records, not importance. A domain with many AME mass rows is not "done", and one CODATA constant can matter more than a dozen table rows.

## What each domain holds and still lacks

This section is generated by `python -m pgi.corpus.coverage gaps` from the board itself. "On the board" groups every record under a described entry in `coverage.HELD`, with counts; a record with no entry fails the tests. "Still missing" lists the entries of `coverage.GAPS` that no record of that domain matches yet. A gap closes itself as soon as a matching record lands, so this list can't claim something is missing once it's on the board. The tests check that the block below equals the generator's output.
